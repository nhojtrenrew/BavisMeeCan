# Structure

```
.kiro/            steering, specs (one folder per feature), hooks, agents
src/
  main.ts         boot: wires the modules together (lead owns this file)
  render/         canvas scaling, letterbox, sprite-sheet animator
  typing/         input (desktop + mobile), scoring
  bavis/          WebLLM worker, model ladder, fallback lines
public/assets/    GENERATED by tools/ (sheets, JSON, SVG); do not edit by hand
assets/src/       sources: *.ase (LibreSprite), *.svg (Affinity exports)
assets/palette/   bavis-21.gpl, the only allowed colours
tools/            asset pipeline scripts (Node, no global installs)
docs/             kiro-log.md, handoff.md, write-up material
```

## Ownership while agents work in parallel
- One lane per spec in `.kiro/specs/`. A builder touches only its lane's folder plus that lane's tests.
- `src/main.ts`, `index.html`, `package.json`, `vite.config.ts` and `.kiro/steering/` belong to the **lead**. Builders request changes to them; they don't make them.
- Branches: `feature/<spec-name>` from `main`, merged by the lead after the verifier passes them.
