# Bavis MeeCan

A weird, PG-13 browser-game homage to early-90s Windows typing edutainment. Bavis MeeCan is a ghostly typing teacher who speaks through a tiny AI model running in your browser. Entry for **Kiroween 2026** (Resurrection category). Built with [Kiro](https://kiro.dev).

**Status:** pre-build. Steering and specs are in [`.kiro/`](.kiro/); the handoff plan is in [`docs/handoff.md`](docs/handoff.md); Kiro usage is logged in [`docs/kiro-log.md`](docs/kiro-log.md).

Bavis MeeCan is an original parody character and game. It isn't affiliated with or endorsed by the makers of any typing software.
